# QA Website Test

This repository contains the QA analysis performed for two web pages provided as part of a technical assessment.

Pages tested:

- https://qualidade.apprbs.com.br/certificacao
- https://qualidade.apprbs.com.br/site

## Test Scope

The following aspects were evaluated:

- UI consistency
- Content quality
- Responsiveness
- Navigation behavior
- Form validation
- User experience

## Test Methodology

Exploratory testing was used to identify usability issues, UI inconsistencies, and potential bugs.

## Repository Structure

test-plan → testing strategy  
test-cases → documented test scenarios  
bugs → detailed bug reports  
evidences → screenshots of issues found  
automation → basic automated tests
